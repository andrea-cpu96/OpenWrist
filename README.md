# OpenWrist  
**An open‑source wristwatch with customizable video playback**

OpenWrist is an open‑hardware and open‑firmware project that transforms a simple digital wristwatch into a creative platform.  
By using a microSD card, users can load their own custom videos, allowing filmmakers, designers, and makers to create a unique *video‑watch* experience.

---

## 🎯 Project Goal
OpenWrist is designed to be a hackable, modular, and fully customizable device.  
The idea is simple: **a wristwatch that becomes a video canvas**, where anyone can upload animations, loops, artwork, or micro‑films.

---

## 🛠️ Key Features
- Video playback from microSD  
- Stable 30 FPS
- Precise RTC
- Accelerometer for turn on via wrist movement
- Fully open‑source firmware and hardware
- Designed for makers, videographers, and digital artists  
- Clear, community‑oriented documentation

## 🎥 How It Works
1. Insert a microSD card into the device  
2. Load a compatible video (use mp4ToAvi.py script to convert .mp4 to compatible .avi frames)  
3. Power on the watch  
4. Enjoy your personalized *video‑watch*
